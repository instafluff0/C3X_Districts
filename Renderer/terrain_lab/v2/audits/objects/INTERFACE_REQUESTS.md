# Q7 convergence interfaces (2026-09-06)

Q7 uses packet v2, module/fixture contract 1 and the unchanged common L21 shader.
It emits full source worked-state geometry/material bindings from all twenty
normalized city pools through an owned packet provider. The first reproducible
witness is `fixtures/objects/generated/city-01/fixture.json`, generated by
`python3 Renderer/terrain_lab/v2/systems/objects/presentation.py --name city-01`.

## Q0 + Q6: shared object receiver/caster data

The current FeatureVertex contains only projected XY/depth, UV, normal and a
material selector. PSFeature evaluates `frame_illumination(form_normal, 1, 1)`:
there is no per-object receiver visibility or world-position input. Packet
composition appends draws; it cannot feed Q7 city casters into the frozen
terrain shadow bake, nor cast building shadows onto neighboring buildings.
Requested interface: generic world mesh + instance transform + material/channel
IDs, ground sampler/anchor, and shared caster/receiver participation. A Q7
building pair with disjoint ground footprints and overlapping sun projections
must show mutual shadow at 0/6/12/18 and preserve identical geometry per phase.
Q6 owns shadow semantics; Q0 owns packet plumbing. Q7 will supply geometry and
transforms, not implement a competing shadow/lighting backend.

## Q0: ground and source anchor query

Publish the projection and sampled ground height/normal for arbitrary tile-local
points, with region/halo identity. Q7 can currently prove synthetic flat-ground
contact; projecting new composed buildings onto source relief cannot be accepted
from guessed heights. Registry mixed/mixed-holdout now available and will be
consumed; real-map identity is no longer an acquisition blocker.

## Current pending items

Final color/alpha attachment adoption follows Q6 color_alpha_v1.json. Authored
socket transforms remain source data; unresolved Light/VFX resources authorize
no invented analytic lights. Static source emissive materials are usable now.
These interface obligations do not stop layout, pool coverage, material intake,
scale/facing/footprint testing, contextual controls, or direct visual iteration.
