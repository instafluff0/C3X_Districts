# Combat effects study

Lab prototype for bombard, naval bombardment, bombing and catapult effects:
sprite-effect graphs drawn over the live unit path. Diagnostic only: no game,
staging or production pack changes.

```
python3 Renderer/lab/studies/combat_effects/sequence.py render SCENARIO     # x64 fixture (VM)
python3 Renderer/lab/studies/combat_effects/sequence.py compose SCENARIO --outcome hit|miss|water
```

## What is data, what Civ III drives

Nothing names a unit. Scenarios only pick units and a camera.

| Layer | Where | Holds |
| --- | --- | --- |
| Effect art | `tools/asset_compiler/effect_graph_profiles.json` | Generic profiles (emitters, flipbooks, `extends`/`scale`, `repeat` sticks and salvos, sprite `pivot`) and `impact_sets` (`shell`, `naval`, `bomb`, `stone` → `hit`/`miss`/`water`/`ship`). |
| Unit metadata | unit pack (generated by the importer) | Per unit: muzzle releases (normalized attack-clip time, socket bone + local offset, profile) and its impact set. |
| Source mapping | `tools/asset_compiler/civ6_combat_effect_map.json` | Importer-only glob rules from source effect names to profiles and impact sets. Other sources add their own map; the runtime never sees source names. |
| Fallback | runtime, by Civ III unit class | Units without metadata: sea → `naval`, bomber → `bomb`, other bombard → `shell`. Units without a model keep native FLCs. |
| Civ III timing | `Renderer/inventory/civ3_unit_action_timing.json` (`tools/asset_compiler/civ3_unit_action_timing.py`) | Per unit ATTACK1/VICTORY/DEATH: FLC length and `.amb`/wav sound cues; `sync_s` = loudest cue's onset (the gunshot; a bomb sample's first blast). |
| Timing | Civ III | Impact at `Unit::play_bombard_damage_animation` (its hit/miss/water/ship FLC and wav, 500 ms per roll); bomb stick's first blast at the VICTORY (bomb FLC) sync; the attack clip is warped so its first release lands on ATTACK1's sync. Normal combat: impacts at each round's end, a hit on the loser and near misses beyond the winner. |

Effects are stateless: every particle is a pure function of profile, event key
and age (`render_core/effect_sampler.h` mirrors
`effect_graph_compiler.sample_effect`; `native/test_effect_sampler.py` checks
exact parity through the flat runtime pack `effects.bin`).

## Motion (no pops)

The runtime already blends local joints between actions (0.12-0.20 s) and
eases facing changes (smoothstep; 0.12 s per 90 degrees); positions follow
Civ III's own movement. New motion goes through the same paths:

- Broadside: ships' line of fire is the clip side (Civ VI `ATTACK_P` port +90,
  `ATTACK_S` starboard -90, importer map). The attack facing target becomes the
  Civ III direction minus the bearing, eased like any facing change. Pending
  pack metadata: a slower turn for large ships (about 0.3 s per 90 degrees) so
  the turn completes before the first broadside (battleship 0.38 s).
- Clip warp: a skipped wind-up starts inside the existing action blend.
- Bomb runs fly at `BOMB_RUN_LIFT` x the Civ III sprite lift (idle hover 0.5);
  pending pack metadata, eased in over the approach and out on the return.

`compose` paints unit layers and effects far to near by anchor depth (flying
units last), standing in for the runtime's depth test of effects against units.

## Runtime (game)

- Pack: `Renderer/packs/CombatEffectsRuntime/effects.bin` + `textures/`
  (`effect_graph_compiler.write_runtime_pack`, local like its sources), with
  `impact/<set>/<outcome>` aliases. Unit pack bindings carry `impact_set`,
  `attack_bearing`, `attack_sync`/`attack_first_release` (only when the warp
  stays gentle), `bomb_blast_s`, `flight_lift`, `turn_scale` and attack
  `release<n>` markers (`unit_combat_bindings.publish`, via `prepare_units`).
- Director: `render_core/combat_effects.h` (releases from the drawn attack
  clip; impacts, bomb releases and combat rounds from Civ III facts).
- Draw: `sandbox/direct_effects.h` after the unit bodies, before tone mapping.
- Bridge: two unit-state kinds (`IMPACT`, `BOMB_RELEASE`) from existing
  inleads; see `Renderer/docs/civ3_patch_dependency_ledger.md`.
- Unit audit (78 pack units): arrow 6, bomb 2, bullet 12, melee 25, missile 7, naval 11, nuclear 2, shell 6, stone 3, torpedo 2. Munitions come from
  Civ VI evidence, else the firing weapon, else Civ III's own data: a Nuclear
  Weapon or Cruise Missile ability, else the unit class. No attack: Settler, Worker.
- Zero native 2D (user rule): every bombard hit/miss, bomb drop (also the
  nuclear delivery), SAM shoot-down and SDI interception is drawn in 3D once
  the pack loads; unknown shooters use the `default`/`default_drop` sets and
  standalone FLCs the `intercept` set. City disorder and plague are captured
  as city flags and drawn as `city/disorder` and `city/plague` loops; fireworks
  are hidden without replacement (user: not suited for 3D).
