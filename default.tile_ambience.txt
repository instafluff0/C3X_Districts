[
  ;  Tile ambience sound config fields (each sound block begins with "#Sound")
  ;  - name                     : Text (required). Internal ambience rule name; must be unique.
  ;  - sound_path               : WAV or AMB filename (required). Use a Civ3 asset path, for example Sounds\Ambience\CoastSurf.wav.
  ;  - mode                     : Text (required). "bed" or "stinger".
  ;                               - bed:      A quiet looping or long-running ambience layer, such as surf, wind, leaves, or city hum.
  ;                               - stinger:  An occasional one-shot detail, such as a bird call, gull, frog, owl, creak, or splash.
  ;  - type                     : Text (required). "terrain", "resource", "city", or "coastal_wave".
  ;                               - terrain:         Matches map terrain. Use terrain_types to narrow it.
  ;                               - resource:        Matches visible resources. Use resource_type to narrow it.
  ;                               - city:            Matches city tiles. Use civs, cultures, city_sizes, and/or eras to narrow it.
  ;                               - coastal_wave:    Matches coast tiles where the coastal-wave animation logic finds a wave edge.
  ;  - terrain_types            : Comma-delimited terrain types. Optional filter for type = terrain.
  ;                               Valid values: desert, plains, grassland, jungle, tundra, floodplain, swamp, hills, mountains,
  ;                                             forest, volcano, snow-forest, snow-mountains, snow-volcano, coast, sea, ocean, land
  ;                               Singular/plural forms are both accepted (for example, volcano/volcanoes).
  ;                               "land" means any non-water tile.
  ;  - resource_type            : Resource name. Optional filter for type = resource.
  ;  - civs                     : Comma-delimited civilization names. Optional owner/territory filter for terrain, resource, coastal_wave,
  ;                               and city rules. Country, singular, adjective, and leader names are accepted, for example Rome, Romans,
  ;                               Roman, or Caesar. For non-city tiles, this matches the tile's territory owner; unowned tiles do not match.
  ;  - cultures                 : Comma-delimited culture groups. Optional owner/territory filter for terrain, resource, coastal_wave,
  ;                               and city rules. For non-city tiles, this matches the tile's territory owner's culture.
  ;                               Valid values: American/AMER, European/EURO, Roman, Mid East/Mideast/MIDEAST, Asian.
  ;  - city_sizes               : Comma-delimited city size filters. Optional filter for type = city.
  ;                               Valid named values: town, city, metropolis. These use the scenario's configured city-size thresholds.
  ;                               Numeric values and ranges are also accepted, for example 1-6, 7-12, 13+.
  ;  - eras                     : Comma-delimited era filters. Optional filter for type = city.
  ;                               Valid values: ancient, middle, industrial, modern, or 0..3.
  ;  - adjacent_to              : Text. Optional adjacency requirements, using the same syntax as tile animations.
  ;                               Comma-delimited values using:
  ;                                 <terrain_or_land>
  ;                               or
  ;                                 <terrain_or_land>:<direction>
  ;                               Direction values: northeast, east, southeast, south, southwest, west, northwest, north
  ;                               Example: coast:southeast, sea, forest:north
  ;  - group                    : Text. Ambience group used for bed replacement and stinger cooldowns. Defaults to name.
  ;  - weight                   : Integer. Higher values are more likely to be chosen when multiple rules match. (default: 10)
  ;  - volume                   : Integer from 0 to 127. Keep beds quiet; recognizable stingers can be a little louder. (default: 35)
  ;  - fade_ms                  : Integer. Bed fade duration in milliseconds. Ignored by stingers. (default: 3000)
  ;  - loop                     : true/false. Defaults to true for beds and false for stingers.
  ;  - min_interval_seconds     : Integer. Minimum seconds before this exact stinger can play again. (default: 90)
  ;  - group_min_interval_seconds : Integer. Minimum seconds before any stinger in the same group can play again. (default: 30)
  ;  - day_night_hours          : Comma-delimited numbers [0..23] and/or inclusive ranges like 6-17.
  ;                               Optional allowed day/night cycle hours. Example: 0-5,19-23
  ;  - seasons                  : Comma-delimited seasons. Optional allowed seasons: spring, summer, fall, winter.
  ;
  ;  Runtime behavior notes:
  ;  - enable_custom_ambience must be true in C3X config.
  ;  - When custom ambience is enabled, Civ3's native random map chirps are suppressed.
  ;  - Candidate rules are sampled around the screen center, so borders and mixed terrain can contribute naturally.
  ;  - District, wonder district, and natural wonder ambience is defined with sound entries in their respective config files, not here.
  ;  - Beds should be subtle and loop cleanly. Stingers should be rare enough that repeated calls do not become irritating.
  ;  - If custom ambience is enabled but no active ambience rules match, no ambient map sound will play.
]
